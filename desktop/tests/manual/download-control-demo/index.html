Comprobación manual de Download Control

Todos los archivos contienen texto fijo de prueba. No son documentos PDF, programas ni instaladores reales.

Selecciona la política en el panel de Qt.

Descargas HTTP

En estos enlaces, el nombre lo proporciona Content-Disposition en la respuesta HTTP.

  • PDF permitido: informe.pdf, aunque la URL termina en .exe
  • EXE bloqueado: programa.exe, aunque la URL termina en .pdf
  • MSI bloqueado: paquete.msi
  • Nombre Unicode permitido: informe-niño.PDF
  • PDF lento: unos 30 segundos para observar la transferencia
  • Fallo provocado: transferencia incompleta para comprobar el aviso de error

Para comprobar el nombre definitivo, abre el PDF permitido y escribe programa.exe en Guardar como.

Para comprobar la cancelación voluntaria, abre de nuevo el PDF permitido y pulsa Cancelar.

Descargas generadas con blob: y data:

Estos enlaces utilizan el mismo texto inerte, generado en la página, sin pedir otro archivo al servidor. El nombre se propone mediante el atributo download del enlace.

  • Blob — nombre PDF: blob-permitido.pdf
  • Blob — nombre EXE: blob-bloqueado.exe
  • Data — nombre PDF: data-permitido.pdf
  • Data — nombre EXE: data-bloqueado.exe

Con Restrictiva, comprobar si los PDF permiten guardar y los EXE se bloquean antes del diálogo. Si un esquema se rechaza antes de iniciar la descarga, registrar el aviso observado.
